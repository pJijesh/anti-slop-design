# Layout

## Structure follows the job

The page is organised around what the visitor came to do. Put the answer or the action first. A page that starts with a vague slogan and a stock illustration has put its own pride ahead of the visitor.

## Break the template deliberately

The default page is: centred hero, three feature cards, testimonials, a final call to action. Do not rebuild it. Instead:

- Use a different order if the job calls for it: a table first, a form first, a price first, a timetable first.
- Vary scale. One thing large, the rest small, on purpose.
- Align to a left edge. Centre only short single lines.
- Use rules, whitespace and alignment to group, not cards inside cards.
- Let a list be a list or a table. Three features do not need three boxes.

## Space and rhythm

- One spacing scale (4, 8, 12, 16, 24, 40, 64) and nothing off it.
- More space between sections than within them, with a clear ratio (at least 2 to 1).
- One page width for text, a wider one only for data or images.

## Shape

- Choose one radius and use it everywhere. Most elements can be square or nearly so.
- Use borders and spacing to group. Use a shadow only for an element that truly floats (a menu, a dialog).

## Phone first, properly

- Design the 390 pixel layout deliberately. Check it has no sideways scroll and tap targets of at least 44 pixels.
- The first screen on a phone must still say what this is and what to do next.

## Landmarks and order

One `<main>`. One `<h1>`. Headings in order. The visual order matches the source order.
